# Intro to Ideal Gas Simulations with LAMMPS
### A Google Colab notebook for teaching students LAMMPS ideal gas simulations without students need to install anything.

This Colab notebook is featured in an article currently under peer review, titled:
Incorporating Computational Chemistry into Introductory Courses with a No-cost, Installation-free Molecular Dynamics Activity in Python
by:  Minh Hoang Huynh, Bailee Rusconi, Srinitha Sridharan, Abhinav Iyer, and Gianmarc Grazioli.

A pre-print of the article is available here:
https://chemrxiv.org/doi/full/10.26434/chemrxiv.15008365/v1
